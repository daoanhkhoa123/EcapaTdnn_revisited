# EcapaTdnn Revisited - Training Repository

This repository provides the **training framework** for the EcapaTdnn model.  
It is intended to be used in conjunction with the inference repository:  
[InferenceVertificationEcapatdnn](https://github.com/daoanhkhoa123/InferenceVertificationEcapatdnn)

---

## Overview
- Implements the training pipeline for **EcapaTdnn**.
- Includes scripts for dataset preparation, model training, and evaluation.
- Serves as the foundation for inference and verification tasks, which are handled in the linked repository.

## Related Repository
